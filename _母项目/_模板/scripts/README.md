# scripts — 可复现的验证与构建脚本

放**能重复跑、结果可判断**的脚本：自检、构建、打包、数据校验、环境探测。

## 约定

- 一个脚本只做一件事，名字说清做什么：`autotest.js`、`make-exe.js`、`check-clean.js`
- 脚本要么**明确成功/失败退出**（非零退出码），要么输出**可判读的数字**。不要输出「看起来没问题」
- 验证脚本的结论写进 `docs/context/RUNBOOK.md` 的验收表，或 `docs/history/` 的「本轮数据」
- 中间产物写到 `artifacts/`（已 gitignore），不要污染项目根

## 与验收的关系

`AGENTS.md` 的「最小验收」写**判据**，这里放**执行判据的脚本**。两者要能对上。

---

*新建项目后，把验证脚本放在本目录，并在 `RUNBOOK.md`「验收」表里引用它们。*
