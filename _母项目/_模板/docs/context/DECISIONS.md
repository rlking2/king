# DECISIONS — 设计决策

> 只记**已经定了**的决策和当时的理由。
> 被推翻的决策**不要删** —— 标「已取代」并链到新决策。为什么当初没那么做，和最后怎么做的一样重要。
> 最后更新：（待填写）

## 格式

```markdown
### D-001 决策标题

- **日期**：YYYY-MM-DD
- **状态**：生效 / 已取代（被 D-00X 取代）
- **背景**：要解决什么问题
- **选项**：考虑过哪些（一定要写被否掉的）
- **决定**：选了哪个
- **理由**：为什么
- **代价**：放弃了什么、接受了什么风险
```
